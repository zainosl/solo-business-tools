## 已在使用旧版

在旧待办页面点击「数据管理 → 下载备份」，在新待办页面点击「数据管理 → 从备份恢复」。CRM 用户在旧页面点击「导出」，再到新 CRM 页面点击「导入」。两个工具使用各自的 JSON 备份。恢复会替换当前工具中的记录，导入前请备份。

此前发布的合并版本保存在本仓库的提交历史中。后续代码、文档、测试和 Issues 分别在两个新仓库维护。
